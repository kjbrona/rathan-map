# RosalitaRP Explorer Archive

This folder contains historical Candidate Survey calibration, audit, review, preview, and report material that is not required by the live RosalitaRP Explorer website.

The production website should not load files from this folder. Archived files are retained for recovery, auditing, or future regeneration work.

If an archived file is needed again, move or copy it back to its original path documented in `CLEANUP-MANIFEST.md`, then run the normal local website and maintenance checks before committing.
